# chp3-실습과제.md

## 데이터 요구 분석 명세서

### 1. 여행상품 관리
- 새로운 여행상품을 계속 개발하고 있다
- 각 여행상품은 1명의 담당 직원이 지정되어야 하며, 직원은 여러 상품을 담당할 수 있다.
- 여행 출발 2주일 전까지 출발 여부를 결정하여 상태값을 업데이트한다.

### 2. 예약 관리
- 고객이 여행상품을 예약한 날짜와 예약금 납부 여부를 관리한다.
- 예약 후 24시간 이내에 예약금이 미납될 경우 예약 취소 상태로 자동 전환한다.
- 전체 여행상품별 예약 상황 및 결제 현황을 실시간으로 확인할 수 있어야 한다.

### 3. 고객 관리
- 고객 등급은 '일반', '우수', '최우수'를 구분한다.
- 등급 업데이트를 위해 고객별 과거 여행 참여 횟수 데이터를 유지한다.
- 고객 ID, 이름, 주민등록번호, 휴대폰 번호, 주소, 등급 정보를 관리한다.

### 4. 직원 관리
- 직원의 담당 업무를 구분하여 저장한다
- 각 직원이 담당하는 여행상품 목록과 해당 상품의 예약 상황을 매핑하여 관리한다
- 사번, 이름, 주민등록번호, 휴대폰 번호, 급여, 담당 업무, 입사일 정보를 관리한다.
